# MacTF

**Неофициальный клиент [dtf.ru](https://dtf.ru) для macOS.**
Не связан с DTF и его владельцами. Посты, комментарии и аккаунты — с сайта dtf.ru,
приложение показывает их в окне Mac вместо браузера.

## Что умеет

- Ленты, темы, теги и поиск
- Посты целиком: картинки, гифки, видео, опросы, спойлеры
- Комментарии с ответами и реакциями, новые с прошлого захода подсвечены
- Уведомления во вкладке и всплывашками macOS
- Сообщения, черновики и редактор постов
- Русский, украинский и английский интерфейс

Нужен macOS 15 или новее, Apple Silicon или Intel.

## Установка

1. Скачайте `MacTF-<версия>.dmg` в разделе **Releases** справа.
2. Откройте его и перетащите **MacTF** в папку **Программы**.
3. Первый запуск. Приложение не подписано в Apple (это платная программа
   для разработчиков), поэтому macOS один раз его остановит:
   - дважды щёлкните MacTF — появится «Не удалось проверить…», нажмите **Готово**;
   - откройте **Системные настройки → Конфиденциальность и безопасность**,
     пролистайте вниз и нажмите **«Всё равно открыть»** рядом с MacTF,
     подтвердите паролем.

   Дальше MacTF запускается как обычно.

   Если кнопки «Всё равно открыть» нет — в Терминале:
   ```
   xattr -dr com.apple.quarantine /Applications/MacTF.app
   ```

## Обновления

**MacTF → Проверить обновления…** (или Настройки → О приложении). Приложение само
скачает новую версию, заменит старую и перезапустится.

## Вход и данные

Вход — через обычную страницу входа dtf.ru внутри приложения. Данные входа
хранятся только на вашем Mac (`~/Library/Application Support/DTF`). Приложение
ничего никуда не отправляет, кроме запросов к dtf.ru и проверки обновлений на GitHub.
